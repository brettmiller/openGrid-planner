OpenGrid Planner - User Guide

Getting Started

1. Enter Your Wall Dimensions

  • Input width and height in the "Surface or Wall Size" fields
  • Select units: mm or inch
  • Tip: The tool auto-converts when switching units - your measurements stay accurate

2. Select Your Printer

  • Choose your BambuLab printer from the dropdown (A1 Mini, A1, P1P, P1S, X1 Carbon)
  • Or select "Custom / Other" and enter your bed size in mm
  • Why it matters: Limits tile sizes to what fits on your print bed

3. Choose Layout Mode

Auto Optimal Mode (Recommended)

  1. Select optimization type:
    • Single tile size: All tiles identical - simpler to print, moderate coverage
    • Multiple sizes (fill space): Uses edge/corner tiles - better coverage, more variety
  2. Set tile size range (Min/Max grids)
    • Leave at default range for all available options
    • Or narrow range (e.g., 6-9) to see only larger tiles
    • Max depends on your printer's bed size
  3. Click Calculate Layout
  4. Click any of the 10 recommended options to preview it

Manual Size Mode

  1. Enter exact tile dimensions (width × height in grids)
  2. Choose optimization (single or multiple sizes)
  3. Click Calculate Layout

4. Select Tile Type

  • Full: Stronger, takes 3m4s per grid
  • Lite: Faster printing (1m38s per grid), uses less material

5. Review Results

  • Summary stats show total tiles, coverage %, and print time
  • Visual preview shows how tiles fit on your wall
  • Parts list details exactly what to print

Important Notes

Edge and Corner Tiles: When using Multiple sizes mode, in real world use the edge and corner tiles could be positioned within the grid layout, not just at the edges. This flexibility may be necessary when the layout includes 1×N tiles (single-grid-wide tiles) since they may not be mountable otherwise.

Tips for Full Bed Usage

When printing tiles that use the full bed size (9×9 grids or similar), follow these tips for best results:

  • Disable Skirt/Brim: Removing these allows for more, or larger, parts on the plate.
  • Calibrations: You may need to disable the auto-flow calibration to gain extra room.
